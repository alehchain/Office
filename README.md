# Office

Repositório com arquivos auxiliares para instalação e configuração em ambiente Windows.

## 📁 Conteúdo do repositório

- `Configuração.xml` — arquivo de configuração utilizado pelo instalador do Office.
- `setup.exe` — executável utilizado no processo de instalação.
- `Instalação cmd.png` — imagem de apoio ao procedimento.

## ⚙️ Instalação

1. Faça o download ou clone deste repositório:

   ```bash
   git clone https://github.com/alehchain/Office.git
   ```

2. Abra o terminal do Windows como **Administrador**.
3. Acesse a pasta onde os arquivos foram baixados.
4. Utilize o `setup.exe` juntamente com o arquivo `Configuração.xml` conforme a configuração desejada.

## 🖥️ Requisitos

- Windows 10 ou Windows 11
- Arquitetura 64 bits
- Permissão de administrador
- Conexão com a internet durante a instalação
